Where the exercises come from: sources mapped to our sections

Reference page · step 1 of rewriting our exercises as ladders (easy, medium, hard) · read on 2026-10-20 · every row names the page or file it was read from

Goal. Our exercises are too easy: most only ask the student to put numbers into a formula. This page lists where problems that need more thinking already exist, which of our sections each source fits, and which problems we can model ours on. We never copy a problem. We write our own, using a source for the idea and credit it where the license asks.
Levels used here. medium = needs two or more ideas, or a choice of method. hard = the student must build a model, answer an inverse question, or check whether something is possible. A pure plug-in problem is not listed.
What I could not read. Corke's book is only an .epub (244 MB) with no text file, so its exercises are not surveyed. The OCW 8.01SC problem sets are PDFs that my reader refuses to open (password protection), so only their titles are known. The UPenn course page returned an error (HTTP 404). Quan Quan's slides contain no exercises. Details are in the tables.
Two corrections to the brief. (1) OpenStax University Physics is licensed CC BY-NC-SA 4.0, not CC BY 4.0, and its current license page also forbids feeding the book to a large language model without written permission (see row 2). (2) The "Modelling and simulation of mechanical systems" course exists on Coursera as part of the Naples specialization.
