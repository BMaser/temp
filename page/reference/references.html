References of the course

Reference page · one numbered list for every course page · the number [n] never changes and is never reused

How to read this page. This list works like the bibliography of a LaTeX book. Every source that a course page names or uses has one entry with a fixed number. On a course page, [12] is a link to entry 12 here. Several sources at once are written [3, 7]. A place inside a source is written after a comma, as in [29, ekf.cpp:264-276] (a file and its lines) or [2, §7.2.2.1] (a section); this is the LaTeX form \cite[p]{key}. Each entry gives the authors, the full title, the publisher or venue, the year, the ISBN or DOI when the source shows one, the address, the license, and the line In your library when you own the source. A question mark ? means that the source does not show that detail, so nothing was guessed. The line Checked says what was really opened: "fetched 2026-10-20" means it was fetched on that day; "not checked" means that nobody opened it yet. The last line of an entry lists the course pages that cite it. The search box keeps the entries whose text contains your words.
