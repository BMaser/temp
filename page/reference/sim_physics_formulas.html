Physics formulas inside Gazebo, Project AirSim and PX4

Every physics formula found in the source code of the three tools, side by side: the PX4-Autopilot source code [29], the Project AirSim source code [30], and for Gazebo the gz-sim [31], gz-physics [32], PX4-gazebo-models [33] and DART [34] source code. Each card gives the formula, what it assumes, its default numbers, the exact code and a link to the lines on GitHub at the version that was read. The chapter tag on each group says where the course teaches it.
